Token & Motion Tasks
⚡ CSS Shimmer Skeleton Pattern

Shared skeleton class for all pages. Add to lib/util.js CSS or inline per page. Zero JS dependency.

@keyframes shimmer {
  from { background-position: -200% 0 }
  to   { background-position:  200% 0 }
}
.skeleton {
  background: linear-gradient(
    90deg,
    var(--surface) 25%,
    var(--card2)   50%,
    var(--surface) 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.4s ease infinite;
  border-radius: 4px;
}

Usage: replace content containers with skeleton divs while awaiting data. Swap class on data resolve.

♿ prefers-reduced-motion Guard

Add to home.html <style> block. Disables all scroll animations for users with vestibular disorders. WCAG 2.3.3.

@media (prefers-reduced-motion: reduce) {
  .will-animate {
    transition: none !important;
    opacity: 1 !important;
    transform: none !important;
  }
  .hero-img {
    transition: none !important;
  }
  .day-block.will-animate {
    transition: none !important;
    opacity: 1 !important;
    transform: none !important;
  }
}

Accessibility
A11y Implementation Plan
🔊 aria-live Regions — Where to Add
  • Toast container (all pages with showToast()): Add aria-live="polite" to the toast div. Screen readers announce toast text when injected.
  • Leaderboard list (scoreboard.html, home.html): Add aria-live="polite" to the <div class="lb-list"> or equivalent. Realtime score updates announced.
  • Login errors: Already in DOM via .login-err — add aria-live="assertive" so errors are announced immediately on auth failure.
🔑 Login Error Message Map

Replace raw error?.message in doSignIn() and doSignUp():

const AUTH_ERRORS = {
  'Invalid login credentials':
    'Incorrect email or password.',
  'Email not confirmed':
    'Check your email for a confirmation link.',
  'User already registered':
    'An account with this email already exists.',
  'Password should be at least 6 characters':
    'Password must be at least 6 characters.',
  'Signup requires a valid password':
    'Please enter a valid password.',
};

const friendly =
  AUTH_ERRORS[error?.message] ??
  'Something went wrong — please try again.';
err.textContent = friendly;
