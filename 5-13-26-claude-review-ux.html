Mobile & Responsive
Breakpoints, Touch Targets, Navigation
Breakpoints

home.html: 6 responsive breakpoints at 480, 500, 700, 768, 860px. Full coverage phone to desktop. Consistent pattern across key pages. No layout overflow detected in evidence. grid cols collapse correctly on narrow viewports.

Touch Targets

Scorecard stepper buttons: 52px height (exceeds 44px WCAG minimum). Score inputs use font-size:1rem — prevents iOS auto-zoom. user-scalable=no removed in commit c9cc497 — pinch-zoom now works. All critical entry surfaces are thumbable.

Navigation Pattern

nav-mobile.css + nav-mobile.js loaded on tournament pages. nav-platform.js on platform pages. Consistent drawer pattern with ← TOURney Platform link injected. Dedup guard _seenHrefs prevents duplicate links (commit a613da5). Hamburger visible on all pages.

Tables on Mobile

overflow-x on scoreboard main tables shipped in UX sprint (10a676f). No horizontal overflow on leaderboard. Score entry uses full-width stepper grid — renders correctly at 320px. Admin table still requires horizontal scroll on mobile (known, lower priority).

Accessibility
ARIA, Focus, Contrast, Labels
MEDIUMEmpty alt on heroLogoImg — home.html:429
Logo image has alt="". Screen readers skip it entirely. For a meaningful brand image the alt should convey the tournament name. Empty alt is semantically "decorative" — the logo is not decorative.
Fix (5 min)In home.html JS after settings load: document.getElementById('heroLogoImg').alt = (map.tourney_name || 'Tournament') + ' logo'; — one line, dynamic per tenant.
LOWNo <main> landmark on key pages
Pages use generic <div> wrappers for primary content. Screen reader users cannot jump directly to main content via landmark shortcut. home.html, scoreboard.html, scorecard.html all affected.
Fix (15 min)Wrap primary content area in <main> element on the three pages above. Zero visual change. Instant a11y win.
INFOaria-live implemented correctly — home.html:450, 680 + scoreboard:276, 302
heroLeaderboard at line 450, toast at line 680 — both have aria-live="polite". Scoreboard both tbody wrappers at lines 276 and 302. Live regions announce score changes to AT users without interrupting in-progress speech. Pattern is correct.
StatusNo action needed. Ship and done.
INFOprefers-reduced-motion guard correct — home.html:381
UX sprint shipped @media (prefers-reduced-motion: reduce) at home.html:381. Zeros transitions, opacity, transform on animated elements. WCAG 2.3.3 (AAA) satisfied for hero fadeUp animations. HIO confetti is the remaining exception — LOW priority.
StatusNo action needed. HIO confetti reduced-motion path is a follow-up, not a blocker.
