What TOURney Is

Multi-tenant golf tournament SaaS PWA. Organizers create tournaments, invite players, run multi-round scoring across 12 formats (individual stroke, team scramble, pairs, etc.), and manage results via a rich admin panel. Players get realtime scorecard, feed with @mentions, leaderboard, champions archive, and course map. Stripe billing gates the pro tier. One live tenant: Bova Invitational 2026.

Council of 5 — Forward-Looking Ideas
1
SECURITY
CSP Script Extraction
Every HTML page has substantial inline <script> blocks — that forces unsafe-inline in the CSP. Extracting them to external .js files unlocks a strict script-src 'self', making the _parseMentions and url innerHTML bugs unexploitable at the browser level before code fixes even land.
Build plan: Extract each page's inline <script> to a paired pagename.js. Replace inline block with <script src="/pagename.js">. Remove 'unsafe-inline' from vercel.json CSP. ~1 day per 3–4 pages, ~4 days total.
