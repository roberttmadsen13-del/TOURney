Brand System — Logo Spec (tourney-brand SKILL.md)
  • Nav logo: Inline <svg id="navLogoSvg" viewBox="0 0 240 48" style="height:24px"> — pasted verbatim into every nav. Never <img src="/logo-nav.svg">.
  • Nav companion: <img id="navLogoImg" style="display:none;height:32px"> alongside navLogoSvg — tourney-init.js swaps src to tournament logo_url and toggles visibility.
  • Hero logo: <img id="heroLogoImg" src="/logo-hero.svg"> — stays as <img> so tourney-init.js can replace .src with tournament logo at runtime.
  • Install hero: <img src="/logo-hero.svg" style="width:140px"> — loaded separately via inline script, not tourney-init.
  • Static files: /logo-nav.svg and /logo-hero.svg exist in repo root, precached in sw.js. Source of truth for design — do not link via <img> in app pages.
