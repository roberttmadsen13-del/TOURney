What TOURney Is

Multi-tenant golf tournament SaaS PWA. Organizers create tournaments via /create, configure brand/format via admin, invite players via email gate. Players RSVP, get scorecards, see live leaderboard. Feed with trash talk + hole-in-one push notifications. Realtime scoring via Supabase. Stripe billing gates tier features. Single codebase, infinite tournaments via slug-based multi-tenancy. Live at tourney.greenskeeper.studio. Bova Invitational is the v1 tenant.

Sprint-21 additions: mygolf_profiles (cross-tournament player identity), donations (donation checkout edge fn), social proof banner, invite gate, PWA install prompt, scoring-open banner, yardage on scoreboard.

⚠ Gaps & Real Bugs
🔴 HIGHfeed.html:377 — _parseMentions XSS
_parseMentions(p.message) sets d.innerHTML = str then calls replace on the result. str is user-submitted feed message content. HTML tags in the input execute before @mention replacement runs. esc() helper exists at feed.html:658 but is not applied to str before it enters d.innerHTML.
FixApply esc(str) before setting d.innerHTML in _parseMentions. Upstream: trash_talk table → feed.html. Downstream: nothing reads feed.html's DOM output. Risk if wrong: @mention display breaks — test both after fix.
🔴 HIGHsend-push — Auth Fix Not Deployed
Auth-gated version of supabase/functions/send-push/index.ts is committed but NOT deployed to Supabase. Live function accepts any tournament_id UUID with zero authentication. Any party who discovers the Supabase project ref can spam push notifications to all subscribers of any tournament.
Fix (Rob manual)npx supabase functions deploy send-push --project-ref jllugkiojeoopitdvzsa. Requires SUPABASE_ACCESS_TOKEN.
🟠 MEDIUMCSP unsafe-inline — Nullifies XSS Protection
vercel.json CSP header: script-src 'self' 'unsafe-inline'. All HTML pages have substantial inline <script> blocks — that's the blocker. The unsafe-inline directive nullifies the XSS protection CSP is meant to provide. Until inline scripts are extracted to /lib/*.js, a strict CSP cannot be set.
Upstream: All 9 tournament HTML pages + 5 platform pages have inline scripts.
Downstream: Strict CSP blocks all inline script execution — must extract first.
Fix: Extract inline scripts to external files, then tighten CSP.
🟠 MEDIUMSEND_INSTALL_EMAIL_SECRET Unset
send-install-email edge function exists. Secret SEND_INSTALL_EMAIL_SECRET has not been set in the Supabase dashboard. PWA install email never fires on registration. Users must manually navigate to install.
Fix (Rob manual) Set SEND_INSTALL_EMAIL_SECRET in Supabase dashboard → Project Settings → Edge Functions → Secrets.
🟠 MEDIUMNo Player-Facing Score Entry
Critical competitive gap vs Unknown Golf. TOURney has zero player score entry UI. Admins must enter all scores. Blocks scale — organizer becomes scorer for all players. Competitor differentiates heavily on per-hole +/- input, par/yards display, player avatars.

Downstream: scoreboard.html reads scores realtime, scorecard.html reads round scores.
