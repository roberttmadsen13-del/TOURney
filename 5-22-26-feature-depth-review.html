Grade Rationale — Feature Depth B+

Down from A− (full-platform reviews). This dedicated axis review surfaces what averaged-grade reviews miss. The core tournament loop is complete and impressive — 12 scoring formats, realtime everywhere, PWA-ready. But three structural gaps hold it off A: (1) no courses/holes DB table — the promised course page doesn't exist and scorecard has no per-hole yardage data model; (2) bug-fab is single-image — platform_bugs.image_data TEXT means one screenshot per report; (3) captain designation has settings keys but no admin write path — team_a_captain and challengers_captain exist in home.html fetch array but admin.html never writes them. Runbook closes all three.

What TOURney Is

Multi-tenant golf tournament SaaS PWA. Each tournament lives at /t/{slug}/. Single-page HTML files served via Vercel static deploy. Supabase for DB + auth + realtime + edge functions. Admin configures everything from /t/{slug}/admin. Players register via home page RSVP form. Scores entered hole-by-hole via scorecard. Scoreboard updates in realtime. Feed shows activity. Bug-fab (owner-only) logs issues to platform_bugs with a screenshot.

Create courses + course_holes migration
Apply migration 016_course_holes.sql via mcp__claude_ai_Supabase__apply_migration.

SQL:
CREATE TABLE courses (id UUID PRIMARY KEY DEFAULT gen_random_uuid(), tournament_id UUID NOT NULL REFERENCES tournaments(id) ON DELETE CASCADE, name TEXT NOT NULL DEFAULT 'Course', tee_box TEXT NOT NULL DEFAULT 'White', created_at TIMESTAMPTZ DEFAULT now(), UNIQUE(tournament_id, tee_box));

CREATE TABLE course_holes (id UUID PRIMARY KEY DEFAULT gen_random_uuid(), course_id UUID NOT NULL REFERENCES courses(id) ON DELETE CASCADE, hole_number INT NOT NULL CHECK (hole_number BETWEEN 1 AND 18), par INT NOT NULL DEFAULT 4 CHECK (par BETWEEN 3 AND 5), yardage INT CHECK (yardage > 0 AND yardage < 700), UNIQUE(course_id, hole_number));

RLS: ALTER TABLE courses ENABLE ROW LEVEL SECURITY; CREATE POLICY "public read courses" ON courses FOR SELECT USING (true); CREATE POLICY "admin write courses" ON courses FOR ALL TO authenticated USING (EXISTS (SELECT 1 FROM tournament_admins WHERE tournament_id = courses.tournament_id AND email = auth.email())) WITH CHECK (EXISTS (SELECT 1 FROM tournament_admins WHERE tournament_id = courses.tournament_id AND email = auth.email()));
Same pattern for course_holes (JOIN to courses to get tournament_id).

Upstream: tournaments table (FK)
Downstream: admin.html Course tab (Step 2), scorecard.html (Step 4), course.html (Step 3)
