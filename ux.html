Review May 12, 2026 claude-sonnet-4-6 B−

Premium aesthetic and solid CSS token coverage (admin.html 224 uses, 25+ pages consistent). Critical gaps surface on deep audit.

🚨 scorecard.html — user-scalable=no in viewport meta. WCAG 1.4.4 fail. Remove immediately — inputs already use font-size:1rem so iOS zoom won't trigger.
⚠️ login.html — raw error?.message from Supabase exposed to users. Map to friendly strings.
💀 No loading skeletons site-wide — blank flash on every data fetch. Known sprint item since 5-8-26 leadership review. Highest-visibility gap.
♿ No prefers-reduced-motion guard on home.html scroll animations. WCAG 2.3.3.
🔊 No aria-live on toast container or live leaderboard. Screen readers miss all dynamic updates.
✅ player.html hamburger: aria-label, aria-expanded, role="menu" — best ARIA in codebase. Use as template.
✅ login.html 3-mode UX (sign-in/sign-up/forgot), button feedback, inline errors, gold focus ring — solid.
✅ scoreboard.html empty-state + toast pattern — correct. Replicate to feed, directory.
📱 install.html logic solid (beforeinstallprompt, standalone detection, timed fallback) but orphaned from player journey.
