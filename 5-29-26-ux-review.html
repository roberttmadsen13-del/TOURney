Superball — full implementation
Superball is a scramble variant where one "super ball" player's tee shot is mandatory on pre-set holes (typically odd holes or hole 1, 4, 7, 10, 13, 16). Scoring: one team score per hole identical to scramble. Twist: admin configures which holes are super-ball-required.
Build plan: 1) Add format to FMT array. 2) Add "superball_holes" setting key (defaults to holes 1,4,7,10,13,16). 3) Scorecard shows which player is super ball this hole. 4) Scoring = scramble logic.
