✅ Previously Skipped — Now Build Free

TOURney's core demo is groups going to courses they've never played. GPS + hole visuals are not luxury features — they're the primary discovery experience for unfamiliar courses. Both can be built at $0 using free-tier APIs.

  • GPS yardage (ball-to-pin) — navigator.geolocation.watchPosition() is free in every browser. Store green lat/lon in holes table (already exists). Pull coordinates from OpenStreetMap Overpass API (no key, free). Haversine formula = real-time yards to pin. Cost: $0.
  • Satellite hole view — Mapbox Static Images API: 50,000 requests/month free. URL is a constructed string: satellite-v9/static/{lon},{lat},16/400x250. Hole coordinates from OSM Overpass. Admin sets course once → all 18 holes auto-generate. Always-current satellite imagery. No manual uploads. Cost: $0 at current scale.
⛔ Do NOT Copy (high cost, low leverage)
  • Strokes gained analytics — requires shot-by-shot data model overhaul. Niche appeal. Unknown Golf targets daily-fee golfers; TOURney targets private invitational hosts.
§ Plan
Strategic Positioning + Roadmap
Where to compete, where to ignore, and in what order to close the gaps that matter.
Strategic Read

Unknown Golf = scoring app that added tournament features. Their UX is player-first — every tab serves the person playing golf. Score input, stats, GPS, weather, social.

TOURney = tournament management platform that hasn't built player-facing scoring. UX is admin-first — organizers get the full platform, players get a leaderboard and trash talk.

These are adjacent but different. TOURney's moat is in the organizer layer: multi-tenant, invite gate, platform artifacts, admin controls. Unknown Golf has no organizer tooling visible. The gap to close is bringing players into the scoring loop without losing the organizer-first positioning.

P1 — Critical
Player-Facing Score Entry
Hole-by-hole +/- input on the player home page. Display par/HC per hole. Admin can still override. This single feature removes the biggest operational burden from every organizer and closes the most visible gap vs Unknown Golf.
P2 — High Value
Side Games
Skins, closest to pin, long drive. Configurable per-tournament. No money tracking required in v1 — just declare winners per game. Casual tournaments care about side games more than the main leaderboard.
P3 — Differentiator
Payouts / Money Tracking
Track buy-in amounts, side game pots, and distribute winnings. Not necessarily payment processing — even a running scoreboard of who owes what adds massive value for casual invitational organizers.
P4 — Polish
Tee Selector + Handicap Display
Let players select their tee on registration or at round start. Display adjusted par and net score on the leaderboard. Unknown Golf shows rating/slope per tee. This closes the handicap scoring gap.
P3 — Free Win (New Course UX)
GPS Yardage + Satellite Hole View
GPS: navigator.geolocation.watchPosition() → Haversine → live yards to pin. No API cost.

Hole image: Mapbox Static Satellite URL built from hole green lat/lon (stored in holes table, populated via OSM Overpass API). 50k free/month. Always-current aerial. Admin enters course name once → all 18 holes auto-populate.

Core demo use case: groups going to courses they've never played. This is the moment of wow.
What TOURney should NOT do to compete
  • Do not pivot to a B2C scoring app — that's Unknown Golf's market. TOURney's differentiation is the organizer layer, multi-tenancy, and invite-gated private events.
  • Do not add strokes gained analytics before scoring entry is even built — wrong order.
  • Do not pay for golf course data APIs (Golfbert, Golf Channel, etc.) — OSM + Mapbox free tier covers the use case at $0.
  • Do not chase Unknown Golf's UI aesthetic (neon green, generic dark theme) — TOURney's premium brand is a genuine competitive advantage.
🏌️ Core Demo Insight (updated 2026-05-21)

TOURney's primary use case is groups playing courses they've never seen. GPS yardage and satellite hole views are not "nice to have" — they are the experience differentiator. Unknown Golf wins on these today. TOURney can match both at $0 using browser APIs + OSM + Mapbox free tier. This moves GPS + hole images from Skip → P3, behind player score entry and side games.

Implementation path: (1) add lat/lon columns to holes table, (2) Overpass API query populates them when admin enters course name, (3) scorecard page renders Mapbox satellite image + live GPS distance per hole.
