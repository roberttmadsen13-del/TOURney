Current Scorecard Hole Display — What Exists

The scorecard (scorecard.html) renders hole data inside a .hole-card div (line 385). The renderHole() function (line 1322) populates exactly three data points per hole:

  • Hole number — document.getElementById('holeNum').textContent = currentHole (line 1326)
  • Par — from coursePars[currentHole - 1], rendered into #holePar (line 1327)
  • Yardage — from courseYards[currentHole - 1], appended inline as · {yd} yd when present (line 1327–1329)

There is no image element, no SVG container, no placeholder, and no CSS class for a hole diagram anywhere in scorecard.html. The .hole-header CSS (line 74) is a flex row containing only hole number and par text.

No image_url, svg_path, diagram_url, or any visual field exists on any course-related table. This feature requires a schema migration before any frontend work.

Data Loading Priority Chain (scorecard.html lines 619–635)

Par and yardage are loaded through a three-tier override chain, highest priority last:

  1. settings table — pars_day* and yards_day* keys for tournament-specific overrides
  2. golf_courses table — gc.pars[] and gc.tees[].yards[] when round has a course_id (line 622–626)
  3. course_holes table — hole_number, par, yardage from tournament's linked courses row (lines 630–635) — final precedence

Hole image would naturally slot into this same chain. The course_holes table is the authoritative per-hole data source and is the right place to add image_url.

Strengths
  • Data pipeline is clean. course_holes is already fetched per-round at scorecard init (line 630). Adding image_url to the select is a one-line change.
  • Hole identity is unambiguous. currentHole (int 1–18) maps directly to array index — no lookup complexity.
  • renderHole() is the single render path. One function owns hole display. Image injection goes in exactly one place.
  • CSS framework in place. .hole-card and .hole-header are already scoped containers.
  • OSM + browser geo are free. Per platform memory: GPS + SVG hole view are available free via OpenStreetMap and browser geolocation — no satellite imagery cost.

Add JS function uploadHoleImage(holeNum, fileInput):
async function uploadHoleImage(holeNum, fileInput) {
  const file = fileInput.files[0];
  if (!file) return;
  const path = `${tournament.slug}/hole-${holeNum}-${Date.now()}.${file.name.split('.').pop()}`;
  const { data, error } = await sb.storage.from('hole-images').upload(path, file, { upsert: true });
  if (error) { console.error(error); return; }
  const { data: { publicUrl } } = sb.storage.from('hole-images').getPublicUrl(path);
  document.getElementById(`holeImg-${holeNum}`).value = publicUrl;
  // Save to course_holes
  await sb.from('course_holes').update({ image_url: publicUrl })
    .eq('course_id', currentCourseId).eq('hole_number', holeNum);
}
