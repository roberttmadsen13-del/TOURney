What TOURney Is

Multi-tenant golf tournament SaaS PWA. Tenants get a full app under /t/{slug}/: registration, scoring, realtime leaderboard, social feed, HIO notifications, and an admin panel. The platform layer (/platform) is a private ops hub — grades dashboard, artifact registry, bug tracker, and tenant management — accessed only by robert.t.madsen13@gmail.com. One paying tenant live (Bova Invitational). Product not yet monetized.

DB Tables — 12 Migrations
  • tournaments — anchor table. owner_email, tier, stripe_subscription_id, stripe_status, status. (migration 001)
  • tournament_admins — email-based admin membership. RLS canonical gate since migration 004. (001+004)
  • players — tenant players. tournament_id FK, team assignment. is_admin dropped (006b). (001+006b)
  • scores — per-hole scores. tournament_id FK + RLS write gate via rounds table. (001+010)
  • settings — key-value store per tournament. Flexible but un-typed (no schema enforcement). (001)
  • rounds — round state control. Write RLS restricts score submission to open rounds. (011)
  • player_accounts — billing + tier. Anon SELECT closed by migration 012 (2026-05-19). (005+012)
  • invitations — invite codes. SELECT USING(true) — any anon can read code existence. (005)
  • push_subscriptions — PWA push endpoints. SELECT USING(true) — readable by anyone. (005)

Strengths
  • Init layer solid. tourney-init.js dual slug detection (path + subdomain), brand color injection, visibility hide/reveal prevents flash, window.tourney.ready Promise on every page.
  • Admin model canonical. tournament_admins table + email-based RLS gate (migrations 004+006b). players.is_admin fully dropped. No drift.
  • 12 clean migrations. 006b rename resolved duplicate prefix. Schema apply order unambiguous. Migration 012 closed player_accounts anon read.
  • Security headers complete. vercel.json: HSTS (2yr+preload), X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy strict-origin.
  • send-push auth gated. JWT auth + owner/admin membership check in edge function index.ts. No unauthenticated push.
  • Error monitoring live. error-monitor.js auto-loaded by tourney-init.js, logs all JS errors + fetch failures to platform_bugs via log-client-error edge fn (commit 1a16516).
  • Android PWA back guard. Sentinel history entry prevents app exit, navigates to tenant home (commit a98de51).
  • Artifacts self-managing. computeAutoArchive() via STAGE_RANK supersedes lower-stage duplicates. Concluded hidden by default (commit 176988a).
  • Stripe plumbing pre-staged. create-checkout + stripe-webhook edge functions exist. DB has stripe_customer_id, stripe_subscription_id, stripe_status columns. Ready to flip on.
  • PWA SW v37. 25-item precache covers all key pages + assets. sw.js served no-store.
Gaps & Real Bugs
  • Stripe dead in prod. STRIPE_SECRET_KEY + STRIPE_WEBHOOK_SECRET unset in Supabase dashboard. create-checkout returns 500. player-upgrade.html checkout flow non-functional. Zero revenue path.
  • LLC not formed. Greenskeeper Studios LLC — 3+ weeks pending. Required before Stripe account approval and EIN issuance. Business C+ blocking.
  • SEND_INSTALL_EMAIL_SECRET unset. send-install-email webhook gate check present (index.ts) but secret not set in Supabase dashboard env. Install emails silently fail or bypass gate depending on implementation path.
  • CSP unsafe-inline persists. vercel.json html CSP: script-src 'self' 'unsafe-inline'. All HTML pages have substantial inline <script> blocks — extracting them is prerequisite to a strict CSP. Known since May 13 review.
  • invitations + push_subscriptions permissive read. Both tables have SELECT USING(true) in migration 005 — any anon can enumerate invite codes and push endpoints.
  • No OG/social meta tags. Zero og:image, og:description, twitter:card across all HTML pages. Tournament share links unfurl as bare URLs. Marketing grade B−.
  • No score admin-edit UI. admin.html has no mechanism to correct a submitted score. Scores locked after submission. Feature gap flagged in master plan.
  • profile.html: no loading skeleton. Blank flash on cold load. All other main pages have shimmer skeletons. Gap from master plan runbook step.
  • Lighthouse CI absent. No automated performance gate in GitHub Actions. Perf B+ relies on manual checks only.
  • No AWS S3 backup. DB lives in Supabase single-region only. No external backup job configured. P1 from May 11 priorities — still open.
  • settings store un-typed. Key-value table with no schema enforcement. Typos in setting keys cause silent misconfiguration. Architecture A with this single gap.
  • No tournament series / season leaderboard. Single-tournament scope only. No multi-event grouping.
