P0 — Bug #1: Icons Rendering as Unicode Text (App-Wide)

P0 Evidence: Bug description contains raw unicode sequences 🗓 ▶ ⚡ 📋 instead of rendered icons. Affects every page. Root cause: an icon font (likely Lucide, Material Icons, or similar CDN-loaded font) is either not loading or has charset encoding issues in the HTML head.

Upstream: Every page's <head> icon font CDN link. Downstream: All icon-bearing UI elements app-wide — nav, buttons, status indicators, admin controls.

Fix target: Grep icon font CDN link across all HTML files. If using a font icon pack, ensure it's either self-hosted or the CDN link is correct and the charset meta tag is present before it.

P0 — Bugs #15–20: push_subscriptions 403 + players 406 (API Errors)

P0 Evidence: Six auto-logged fetch errors: five are 403 on push_subscriptions upsert across scoreboard, profile, directory, scorecard, and admin pages. One is 406 on players fetch on profile page.

403 root cause: Migration 017 was written to fix this (drop old "player insert own subscription" policy, update UPDATE policy). These bugs are dated 2026-05-23 — Migration 017 may not have been applied to production. Verify via Supabase dashboard.

406 root cause: players query at profile.html uses .single() on a query that returns zero rows (no player record exists for that email+tournament combo). PostgREST returns 406 for .single() with no rows. Fix: change to .maybeSingle().

Upstream: Supabase RLS policies on push_subscriptions and players tables. Migration 017. Downstream: Every authenticated page that upserts push subscriptions. Profile page player lookup.

Upstream: tourney-init.js slug → tournament lookup → window.tourney.ready. Downstream: statRegistered, spotsLeft counters, player field grid.
